# Demo Project

A tiny sample repo for demonstrating Context Check. The claims below are
intentionally wrong so the extension has something to flag.

## Build

```bash
npm run biuld
```

## Test

```bash
npm run tset
```

## Layout

The entry point is `src/services/auth.ts`.
The router lives at `src/routes/index.ts`.
Shared types are in `src/Services/types.ts`.
